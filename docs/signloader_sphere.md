# SignLoader-Sphere：符号对齐时保留 L2 范数

实现文件：`blades/adversaries/spear_sl_sphere_adversary.py`。
这是基于现有 SPEAR-SL 的独立实验变体；原 `spear_sl_adversary.py` 保留作对照。

## 1. 先区分三个量

设原 SPEAR 更新为 \(g=\mu+z\sigma\)，符号调整后为 \(x\)。

1. **范数变化**：\(|\|x\|_2-\|g\|_2|\)。它只描述向量的长度变化。
2. **修改距离**：\(\|x-g\|_2\)。它同时反映长度和方向变化。
3. **偏移保留**：\(\widehat\sigma^T(x-\mu)\)，其中
   \(\widehat\sigma=\sigma/\|\sigma\|_2\)。这是沿原 SPEAR 方向的线性投影。

第 1 个量为零，并不意味着第 2 个量很小，更不意味着训练攻击效果保持。
例如 \(x=-g\)，二者范数相同，但方向完全相反。

若仅翻转集合 \(F\) 内的符号，保持每个坐标绝对值不变，则

\[
\|x\|_2=\|g\|_2,\qquad
\|x-g\|_2^2=4\sum_{j\in F}g_j^2.
\]

所以“保持范数”很容易；真正需要优化的是**被迫改号的能量，以及如何分配剩余幅值**。
如果必须逐坐标匹配另一条梯度的符号，大幅值坐标也可能被迫翻转。
仅匹配正、零、负数量时，可以选择坐标，因而有更大的优化空间。
本实现使用后者，与当前代码的全向量符号统计接口一致。

## 2. 原代码为什么可能削弱原 SPEAR 更新

原 `_adjust_signs_comprehensive` 把正数改为已有的最接近零负数，把负数改为已有的
最小正数，缺少该符号时还会使用固定的 `0.01`。这会同时改变符号与幅值，且固定
`0.01` 不随梯度尺度变化。

例如 \((-0.01,-0.02,-0.03,1)\) 要变成三个正数、一个负数，原代码会把前两项改为
\(1\)，得到 \((1,1,-0.03,1)\)。符号数量正确，范数却从约 \(1.0007\) 增至
\(1.7323\)。该例说明机制问题，不代表所有训练轮次都会增大范数。

此外，原实现对 \(\mu+z\sigma\) 做 DnC 搜索后才修改符号，因此 DnC 看到的候选
不是最终上传的向量。符号调整也可能改变范数、与良性更新的距离和谱投影。

## 3. 新的联合优化问题

从可见良性更新中计算平均正、零、负数量，用最大余数法取整为
\((p_*,o_*,n_*)\)，总和始终等于维度 \(d\)。设

\[
R=\|g\|_2,\quad k=p_*+n_*,\quad
\epsilon=\epsilon_{rel}R/\sqrt{k}.
\]

非零幅值下界防止浮点数中的“负零”和“正零”被统计成零。默认
\(\epsilon_{rel}=10^{-6}\)，它随当前向量尺度变化。

定义可行集合

\[
\mathcal C=\{x:\ N_+(x)=p_*,\ N_0(x)=o_*,\ N_-(x)=n_*,\
\|x\|_2=R,\ |x_j|\ge\epsilon\text{ whenever }x_j\ne0\}.
\]

对每个权重 \(\lambda\ge0\)，求

\[
x_\lambda\in\arg\max_{x\in\mathcal C}
\left(g/R+\lambda\widehat\sigma\right)^Tx.
\]

这等价于在 \(\mathcal C\) 中最小化

\[
\|x-g\|_2^2-2\lambda R\widehat\sigma^T(x-\mu).
\]

- \(\lambda=0\)：所有满足符号数量和原范数的向量中，离原 SPEAR 向量最近的解。
- 增大 \(\lambda\)：允许更大的修改距离，争取保留更多原 SPEAR 偏移。
- 所有权重始终保持同一范数和同一目标符号数量。

这里的“保留”是明确的线性投影指标，不是对最终测试准确率的保证。

## 4. 如何求解：排序与球面幅值分配

记 \(q=g/R+\lambda\widehat\sigma\)。

**符号分配。** 按 \(q_j\) 升序排序，最小的 \(n_*\) 个坐标分配负号，
接下来的 \(o_*\) 个分配零，最大的 \(p_*\) 个分配正号。
每个权重都重新排序，而不是把第一次选中的改号坐标永久锁定。

这是重排不等式的应用：给定各幅值与符号的多重集合，与 \(q\) 同序的排列使内积最大。
因此总存在一个最优解具有上述负、零、正分组。

**幅值分配。** 在非零坐标上写 \(x_j=s_ja_j\)，\(c_j=s_jq_j\)。
如果存在 \(c_j>0\)，则最优幅值为

\[
a_j=\max\{t\max(c_j,0),\epsilon\},\qquad
\sum_j a_j^2=R^2.
\]

右侧关于 \(t\) 单调，用一维二分求解。实现把计算归一化到单位球面，避免直接计算
大半径的平方。

其全局最优性可从球内的线性优化理解：存在正系数时，最优点会用完范数预算；
KKT 条件给出以上阈值形式。符号与排序组合后得到整个问题的全局最优解。

若全部 \(c_j\le0\)，则其余幅值取 \(\epsilon\)，把剩余平方范数分配给最大
\(c_j\) 的坐标。令 \(a_j=\sqrt{\epsilon^2+t_j}\) 后，这是单纯形上的凹函数
最小化，最优解可取一个顶点。代码也处理了这个分支。

在实数运算中范数相等；浮点实现存在舍入误差。实现支持 float32/float64，保持
输入设备与 dtype；不可表示的结果会报错。

## 5. 范数、距离和方向之间的保证与限制

同一可行集合中，随 \(\lambda\) 增大，最优解的
\(\widehat\sigma^Tx_\lambda\) 不减，而 \(g^Tx_\lambda\) 不增，
因此 \(\|x_\lambda-g\|_2\) 不减。这是两个目标的权衡。

等范数时，距离和原向量余弦有精确关系：

\[
\|x-g\|_2^2=2R^2\bigl(1-\cos(x,g)\bigr).
\]

因此限制 \(\|x-g\|_2/R\le\tau\) 就能保证
\(\cos(x,g)\ge1-\tau^2/2\)。默认 \(\tau=0.5\) 对应下界 \(0.875\)；
更严格的 \(\tau=0.35\) 对应 \(0.93875\)，但更容易不可行。

这仍不保证偏移 \(x-\mu\) 的方向。例如 \(\mu\) 很大、\(z\sigma\) 很小时，
相对 \(g\) 很小的修改也可能抹去大部分攻击偏移。
当 \(z\|\sigma\|_2>0\) 时，柯西不等式只给出

\[
\frac{\widehat\sigma^T(x-\mu)}{z\|\sigma\|_2}
\ge 1-\frac{\|x-g\|_2}{z\|\sigma\|_2}.
\]

**有些符号目标与偏移保留根本不能同时满足。** 取
\(g=\sigma=(1,1,1),\mu=0\)，目标为两个正数、一个负数，保持范数 \(\sqrt3\)。
即使允许任意幅值分配，沿原方向的未归一化投影最大也只有

\[
-\epsilon+\sqrt{2(3-\epsilon^2)}<3.
\]

当 \(\epsilon\to0\)，最多保留 \(\sqrt{2/3}\approx81.65\%\)，无法达到 90%。
任何声称对任意符号目标都能同时保范数、保方向、保攻击效果的方法都不成立。

等范数也不能保持所有良性距离。对任意良性向量 \(b\)，

\[
\|x-b\|_2^2-\|g-b\|_2^2=-2b^T(x-g).
\]

因此面对其他防御的效果仍需实验。匹配全向量直方图也不等于匹配随机窗口直方图。

## 6. 与当前 SPEAR 流程的接合

每轮使用实际参与的恶意客户端数量。对有限网格 \(z\in\{0,0.5,\ldots,5\}\)：

1. 生成原候选 \(g=\mu+z\sigma\)。
2. 计算 \(\lambda=0\) 最近解。若它也超过硬距离预算，该半径下无可行解，跳过。
3. 计算 \(\lambda\in\{0,0.25,1,4\}\) 的解，保留预算内的候选。
4. 达到偏移保留目标的候选中选距离最小者；若候选池没有达标解，选投影最大者并
   记录 `retention_target_met=False`。有限网格未找到不等于数学上不存在。
5. 对**最终已对齐的向量**运行 DnC 代理检验。若未全部通过，再检验不同的最近解，
   每个 \(z\) 最多两次完整代理调用。
6. 跨 \(z\) 按代理通过人数、实际保留偏移、较小修改距离依次选择，提交检验过的向量。

代理在同一轮复用本地随机坐标子集，使候选比较使用相同条件；并不知道服务器的
真实随机子集。若没有候选全部通过，会记录 `proxy_all_passed=False` 并发出日志，
不声称通过。若所有半径都不满足符号、范数和硬距离预算，则报错，不悄悄突破预算。

与原 10 次二分相比，这里使用有限网格，不假设经过符号修改后的通过情况随 \(z\)
单调。默认最多 22 次完整代理调用，而每次仍有 5 次子空间 SVD，计算可能更贵。
这是研究原型，完整训练前应先量测每轮耗时。

## 7. 使用方法与记录

原程序中配置 adversary 的位置改用完整类路径即可，不需要改包的 `__init__.py`：

```python
adversary_config = {
    'type': 'blades.adversaries.spear_sl_sphere_adversary.SPEARSLSphereAdversary',
    'retention_target': 0.9,
    'max_relative_l2': 0.5,
    'direction_weights': [0.0, 0.25, 1.0, 4.0],
    'z_values': [0.0, 0.5, 1.0, 1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0],
    'visible_benign_limit': None,
}
```

`visible_benign_limit=None` 沿用本轮全部良性更新可见的设定；设为正整数后，每轮随机
抽取最多该数量的良性更新，所有统计与代理检验都只使用该子集。这是信息受限消融，
并没有实现“完全看不到良性更新时从本地数据估计”的另一个威胁模型。

如果只研究数学投影，不跑训练：

```python
import torch
from blades.adversaries.spear_sl_sphere_adversary import project_sign_sphere

g = torch.tensor([-0.01, -0.02, -0.03, 1.0], dtype=torch.float64)
x = project_sign_sphere(g, (3, 0, 1))  # 顺序：正、零、负
print(g.norm(), x.norm(), (x - g).norm())
```

每轮结果可从实例的 `last_diagnostics` 读取，包括 `original_norm`、`final_norm`、
`relative_l2`、`direction_retention`、`retention_target_met`、`proxy_passed`、
`proxy_all_passed`、`observed_benign`、`z` 与 `direction_weight`。
原始偏移为零时，保留率是 `None`，不伪造为 100%。这些字段目前不是自动持久化的
实验指标，需由现有训练记录流程读取。

## 8. 应该如何验证论文里的贡献

至少区分：SPEAR、原 SPEAR-SL、纯符号翻转保幅值、Sphere 的 \(\lambda=0\) 版本、
完整方向权衡版本。先固定相同 \(z\)、相同目标直方图，隔离符号组件自身的影响；
再比较完整搜索流程。否则搜索策略改动可能混入组件收益。

对相同数据划分、客户端采样、随机种子和训练预算，比较 SignGuard、DnC 及原论文
中的其他防御，报告最终准确率、每轮范数误差、相对修改距离、偏移保留率、真实防御
通过率和耗时。不要用本地 DnC 代理通过率替代服务器通过率。

球面约束、重排不等式和线性目标权衡本身是已有数学工具。可研究的贡献是它们在
SPEAR 符号调整中的联合建模、可行性分析与跨防御实证；当前实现不能单独证明
“首次提出”或“攻击效果更好”。此前只取得 ScaleSign 摘要，未取得全文，不能据此
断言它没有类似约束或其具体最优化实现不同。
